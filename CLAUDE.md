# Règles du projet

## Persistance des contenus générés

À chaque fois que tu génères du contenu (code, texte, idée, plan, analyse, résultat, etc.), tu dois :

1. **Toujours écrire ce contenu dans un vrai fichier** sur le disque, dans le dossier du projet (utilise un sous-dossier clair comme `/outputs`, `/notes` ou `/scripts` selon la nature du contenu).

2. **Utiliser un nom de fichier explicite**, si possible daté (ex: `idee_2026-09-18.md`, `script_traitement.py`, `analyse_resultats.txt`), pour qu'il soit facile à retrouver.

3. **Ne jamais te limiter à une réponse uniquement affichée dans le chat** sans l'écrire aussi dans un fichier, sauf si l'utilisateur dit explicitement "ne sauvegarde pas" ou "juste pour discuter".

4. **Avant de régénérer quelque chose**, vérifie d'abord si un fichier correspondant existe déjà dans le projet (cherche dans `/outputs`, `/notes`, etc.) plutôt que de tout refaire depuis zéro.

5. **À la fin de chaque tâche**, indique clairement le chemin exact du ou des fichiers créés ou modifiés.

## Pourquoi ce fichier

Ce fichier est lu automatiquement par Claude Code à chaque nouvelle session dans ce projet.
Contrairement à une instruction collée dans le chat, cette règle reste donc active en permanence, même après fermeture de VS Code ou changement de conversation.
